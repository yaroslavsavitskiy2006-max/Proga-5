# Proga-5 — задания по блокчейну и квантовым вычислениям

Учебный набор из 15 самостоятельных Python-скриптов. Темы включают хеширование, простую модель блокчейна, Proof-of-Work, дерево Меркла, Tangle, цифровые подписи и базовые расчёты для квантовых вычислений.

## Запуск

Требуется Python 3; внешние пакеты не используются. Запустите нужное задание из корня репозитория:

```bash
python task_01.py
```

Файлы `task_01.py`–`task_15.py` можно запускать по отдельности.

## Задания

| Файлы | Темы |
|---|---|
| `task_01.py`–`task_02.py` | Пропускная способность, соотношение чтения и записи |
| `task_03.py`–`task_07.py` | Блоки, SHA-256, Proof-of-Work, дерево Меркла, модель атаки 51% |
| `task_08.py`–`task_11.py` | Tangle/DAG, подтверждение транзакций и индексирование |
| `task_12.py` | Упрощённая модель цифровой подписи |
| `task_13.py`–`task_15.py` | Кубиты, алгоритм Шора и оценка роста числа кубитов |

Это учебные модели, а не реализация криптографических протоколов для реального использования.
